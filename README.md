# Sistema de Gestión de ALBERCAS DEL INDEHVAL

Proyecto académico desarrollado por Kevin Hernandez Ramos

Sistema de gestión de albercas con interfaz gráfica en Python, conectado a una base de datos SQLite y con importación de datos desde un archivo Excel proporcionado por INDEHVAL.

Tecnologias Utilizadas para el desarrollo

Python (lenguaje principal)
CustomTkinter (interfaz gráfica moderna)
SQLite (base de datos local)
Pandas + OpenPyXL (lectura de archivos Excel para la visualizacion de la bd del INDEHVAL)

Requisitos previos

Antes de ejecutar el proyecto, necesitas tener instalado:

- **Python 3.10 o superior** → [Descargar aquí](https://www.python.org/downloads/)
- **Git** → [Descargar aquí](https://git-scm.com/)
